# Third-party assets

DuckRobe previews the real Pollen Robotics Microduck using its publicly published
official simulation assets. Source files are preserved locally and pinned to
fixed revisions.

## Native simulation model

- Repository: https://github.com/pollen-robotics/microduck_rl
- Revision: `8d0db74916a4f833d1d9b95d6a1d7f4d13b9d5ec`
- Original directory: `src/mjlab_microduck/robot/microduck/`
- Local model: `public/robot/source/robot_allcollisions.xml`
- Local meshes: `public/robot/source/assets/` (the model's 38 referenced STL files)
- Declared repository license: Apache License 2.0; Copyright 2026 Pollen Robotics.
- The unmodified upstream license is included at `public/robot/source/LICENSE`.
- XML dynamics, actuator definitions, inertial parameters, contacts and equality
  constraints are retained in the source model.

## Browser geometry generated by DuckRobe

- Local file: `public/robot/web/microduck.glb`.
- Input: the 38 original STL files from the native simulation repository above.
- Rebuild: `node scripts/build-robot-glb.mjs` (no network or external converter).
- The converter applies each native MJCF mesh scale and welds exactly identical
  vertex positions into indexed geometry. It preserves all source triangles;
  it performs no geometric simplification and does not use the HF browser GLB.
- The GLB retains original STL filenames as its 38 mesh/node names. Materials
  and body assembly are supplied by DuckRobe's renderer.
- The generated GLB derives exclusively from the Apache-2.0 simulation files.

## Browser kinematics generated by DuckRobe

- Local file: `public/robot/web/kinematics.json`.
- Input: the pinned native `robot_allcollisions.xml` above, under Apache-2.0.
- Rebuild: `node scripts/build-robot-kinematics.mjs`.
- The converter exports the official MJCF's 15 bodies, 14 actuated joints and
  70 visual mesh instances, preserving their body-local frames. It resolves
  default classes and material RGBA for visual attributes. The original XML
  remains authoritative for dynamics and collisions.
- Wardrobe geometry and kinematics are generated exclusively from the native
  simulation repository. The Playground uses separately pinned HF physics
  assets as described below; no runtime fetch goes to the HF Space.

## Official Web reference

- Reference: https://huggingface.co/spaces/pollen-robotics/microduck-simulator
- Reference revision: `023172c8a7d629b5258d90364c13bafe013abbfa`.
- The official browser simulator was used to verify assembly and appearance.
  Its README is archived as `public/robot/web/SOURCE_README.md` for reference;
  it is not a runtime model input.
- Pollen Robotics's [official press kit](https://pollen-robotics.com/microduck/press-kit/)
  states that its open-source description covers the software stack and excludes
  mechanical and electronic design files. DuckRobe's downloaded meshes are
  simulation/display assets, not a manufacturing source release.

`public/robot/manifest.json` records every downloaded URL, byte size and SHA-256,
plus both generated renderer files' input files, converters, revisions and
output hashes.
DuckRobe's renderer assembles those official parts independently, applies its own
soft cream/orange materials, and adds decorative preview animation. Clothing and
accessory geometry authored for DuckRobe is separate from the native robot.

## Dressed duck Playground

- Upstream: [Pollen Robotics Microduck Sandbox](https://huggingface.co/spaces/pollen-robotics/microduck-simulator/tree/023172c8a7d629b5258d90364c13bafe013abbfa).
- Revision: `023172c8a7d629b5258d90364c13bafe013abbfa`.
- `public/playground/manifest.json` pins source URLs, SHA-256 hashes and sizes
  for the walking ONNX policy, physics MJCF, collision-source GLB and reference
  kinematics. These are separate from the wardrobe/export physics model.
- `src/playground/arena.js` adapts `app/src/game/arena.js`; the controller,
  constants and collision preparation adapt the same revision's `game.js`,
  `constants.js` and `duck.js`. Source links and original hashes are recorded
  in the Playground manifest.
- The React shell, extra activities, audio, multiplayer and roller policies
  are not included. The flat grid and walls retain the upstream visuals;
  DuckRobe supplies its own controls and wardrobe rendering.
- Runtime packages: `@mujoco/mujoco` 3.11.0 and `onnxruntime-web` 1.27.0,
  pinned in the lockfile. Vite serves their WebAssembly files locally.
